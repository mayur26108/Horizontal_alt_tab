# Horizontal_alt_tab
The mouse with horizontal scroll option(non MX master mouse), don't have the option to configure it to switching tab,(alt+tab)using this repo you can do it

Install python if not installed already
Then double click on this program, it won't pop any application on top
It keeps running in background
When you want to end it go to task manager and search for python and "end task"
Download file and save it as file_name.pyw
